Rank Within Each Year

dense_rank() OVER (
    PARTITION BY t.start_year
    ORDER BY r.average_rating DESC
) AS year_rank

Partition selects the group. Window ordering selects rank order.

Filter After Ranking

WITH ranked AS (
  SELECT t.primary_title,
         dense_rank() OVER (
           PARTITION BY start_year
           ORDER BY average_rating DESC) AS year_rank
  FROM imdb_course.titles t
  JOIN imdb_course.ratings r USING (title_id)
)
SELECT * FROM ranked WHERE year_rank <= 3;

A Running Total Has a Frame

sum(movies) OVER (
    ORDER BY start_year
    ROWS BETWEEN UNBOUNDED PRECEDING
             AND CURRENT ROW
) AS running_total

Counts 3 and 1 produce running totals 3 and 4.
