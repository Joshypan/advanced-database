Insert Documents

mongoose_collection.insert_many([
    {"name": "Meercat", "does_not_eat": "Snakes"},
    {"name": "Yellow mongoose", "eats": "Termites"},
])

Setup already ran this insertion.

Find One Document

yellow = mongoose_collection.find_one(
    {"eats": "Termites"}
)
print(yellow["name"])
print(yellow["_id"])

Result: a dictionary, or None

Filters

Filter Selects
{} All documents
{"name": "Meercat"} This name
{"weight": {"$gt": 1}} Numeric weight greater than 1

Add a Field with an Update

result = mongoose_collection.update_one(
    {"name": "Meercat"},
    {"$set": {"weight": 2}},
)

Filter first. Change second.

Which document now has a weight?

Query Results Through a Cursor

cursor = mongoose_collection.find(
    {"weight": {"$gt": 1}}
)
mongooses = list(cursor)

What Does Each Line Print?

print(len(mongooses))
print(list(cursor))
print(len(mongooses))

1, then [], then 1

No Matching Document

query = {"weight": {"$gt": 300}}

print(mongoose_collection.find_one(query))
print(list(mongoose_collection.find(query)))

None versus []

An Identifier in a Web Address

from bson.objectid import ObjectId

identifier = str(yellow["_id"])
found = mongoose_collection.find_one(
    {"_id": ObjectId(identifier)}
)

Convert back to the stored value type.

Delete the Record We Read

old = mongoose_collection.find_one(
    {"name": "Meercat"}
)
result = mongoose_collection.delete_one(
    {"_id": old["_id"]}
)

result.deleted_count is 1

Reinsert the Same Name

mongoose_collection.insert_one(
    {"name": "Meercat", "does_not_eat": "Snakes"}
)
