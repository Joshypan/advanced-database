A Join Produces Movie Rows

SELECT t.primary_title, t.start_year,
       r.average_rating, r.num_votes
FROM imdb_course.titles t
JOIN imdb_course.ratings r USING (title_id)
WHERE r.num_votes >= 1000;

The inner join leaves out unrated titles.

Grouping Produces Yearly Rows

SELECT t.start_year, count(*) AS movies,
       round(avg(r.average_rating), 2) AS mean_rating
FROM imdb_course.titles t
JOIN imdb_course.ratings r USING (title_id)
WHERE t.start_year IS NOT NULL AND r.num_votes >= 1000
GROUP BY t.start_year
ORDER BY t.start_year;

What the Dashboard Measures

Output Meaning
movies Qualifying titles in this sample
mean_rating Equal-weight mean of title ratings
start_year Reported release year

Source order and filtering affect the chart.

WHERE and HAVING

-- Keep rows before grouping.
WHERE r.num_votes >= 1000

-- Keep groups after aggregation.
HAVING count(*) >= 5

A group threshold belongs after GROUP BY.

Worked Example: Movie Length

Files: database.py, app_basics.py

Compare yearly counts and average ratings after excluding shorter movies.

Number input -> cached function -> SQL filter -> yearly report

The stored data stays unchanged.

1. Add the SQL Filter

In database.py, extend yearly_summary:

def yearly_summary(minimum_votes=1000, minimum_movie_length=0):

Add this condition before GROUP BY:

AND t.runtime_minutes >= %s

Replace the parameter tuple:

(minimum_votes, minimum_movie_length)

2. Add the Input

In app_basics.py, below the minimum-votes input:

minimum_movie_length = st.sidebar.number_input(
    'Minimum movie length (minutes)',
    min_value=0, value=0, step=10,
)

The selected number is a movie length in minutes.

3. Connect the Input to the Query

Replace the cached function in app_basics.py:

@st.cache_data(ttl=60)
def summary(votes, minimum_movie_length):
    return database.yearly_summary(votes, minimum_movie_length)

Inside with second:, replace the call:

rows = summary(votes, minimum_movie_length)

4. Compare the Results

Save both files; run or reload the starter:

streamlit run app_basics.py --server.address 0.0.0.0
