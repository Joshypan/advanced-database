Advanced Database System Design

Fall 2026 / Gregory S. DeLozier, PhD / MW 5:30-6:45

Explore how applications preserve their state and use databases, beginning with SQLite and SQL, then moving through web applications, data access libraries, and MongoDB.

Chapters

Chapter 0: Why Use Databases?
External data, persistent application state, and the course outline.
 Chapter 1: Working with SQL in SQLite
Creating, querying, and changing records with SQLite.
 Chapter 2: SQL in Python
Connections, parameterized queries, returned rows, and commits.
 Chapter 3: Introduction to Web Applications
Flask routes, templates, forms, and persistent application state.
 Chapter 4: Database Abstraction
Abstraction layers, single responsibility, and database operations.
 Chapter 5: Database Constraints
Owners, foreign keys, required values, and rules for related records.
