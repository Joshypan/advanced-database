Integrity Rules in the Database Layer

SQLite constraint Python check in database.py
Required, nonblank text Validate name and type
CHECK (age >= 0) Reject negative age
Required foreign key Find the selected owner
ON DELETE RESTRICT Block deletion of an owner with pets

Same rules. Our database layer now enforces them.
