Install MongoDB in a Codespace, then import real movie records

From Atlas to a Process We Own

Atlas ran the database server for us.

Today the server is a process in our Codespace.

Job Proof it worked

Server and Clients

Component Role
mongod The database server process
mongosh Interactive client
PyMongo Python driver
Import script A Python program using PyMongo

Installing a driver does not install a server.

Where Everything Runs

Piece Where Reachable from
mongod Codespace 127.0.0.1 only
Python, mongosh Same Codespace The same machine
Database files data/db/ in the workspace The server process
IMDb files data/imdb/ The import script

Leave the database port unforwarded.

Build the Connection String

read -s -p "siteAdmin password: " MONGO_PW; echo
HOSTPART="127.0.0.1:27117/?authSource=admin&directConnection=true"
export MONGODB_URI="mongodb://siteAdmin:${MONGO_PW}@${HOSTPART}"

The password is typed, not echoed.

Types Matter

db.titles.countDocuments({start_year: 1994})
db.titles.countDocuments({start_year: "1994"})

The second count is 0: the stored year is a number, not text.

A missing year is null. Genres are still one text value.

Two Collections, One Identifier

SQLite chapters MongoDB here
Tables titles, ratings Collections titles, ratings
tconst primary key _id
Foreign key between them Same _id value; not enforced
Join in SQL Look up by _id in the application

MongoDB indexes _id only. Everything else is a scan until we add indexes.
