Indexes for Actual Queries

Index Query pattern
start_year, primary_title One year, ordered titles
primary_title Exact title equality
num_votes descending Most-voted titles

Ordinary title indexes do not solve arbitrary substring search.

Read the Plan

EXPLAIN (ANALYZE, BUFFERS)
SELECT title_id, primary_title
FROM imdb_course.titles
WHERE start_year = 1994
ORDER BY primary_title;

The chosen plan depends on the data and query.
